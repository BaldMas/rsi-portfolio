Движок 1 — score_coin.py · AI-ассистированный

Путь
/home/masus/CRYPTO/dropstab/
Запуск
cron 21:00 UTC ежедневно (auto_score_unified.py)
ИИ
claude-opus-4-8 + web_search
Режим
ultrathink (до 600 сек/монета)

Принцип. Двухэтапный гибридный скоринг. Этап 1 — количественные пункты (QUANT_CRITERIA) считаются детерминированно по API-данным без AI. Этап 2 — качественные пункты отдаются Claude: скрипт собирает все данные в структурированный промпт и вызывает claude CLI с инструментом web_search, который самостоятельно дополняет анализ свежими данными из интернета. Claude возвращает JSON с баллами и обоснованием по каждому критерию. Результат кэшируется на 7 дней (QUAL_CACHE_DAYS). Количественные пункты пересчитываются при каждом запуске.

Разделение: API-авто пункты 1, 4, 12, 13, 14, 17, 23, 24, 29  ·  Claude остальные 20 пунктов

Движок 2 — scorer.py · Полностью автоматический

Путь
/home/masus/CRYPTO/программирование/
Запуск
cron: каждые 4ч +20 мин (20 */4 * * *)
Источник данных
data.db (SQLite, заполняет data_collector.py)
ИИ
нет — только алгоритм

Принцип. Полностью детерминированный скоринг без AI. data_collector.py (watchdog каждые 30 мин) собирает рыночные данные в SQLite таблицы. scorer.py читает последние записи из каждой таблицы, применяет пороговые функции score_from_brackets() и усредняет суб-баллы в итоговый балл по пункту. Пункты которые нельзя автоматизировать (нарратив, команда, конкуренты) получают нейтральный балл 3. Результат сохраняется в таблицу scores сразу после каждого тикера (commit per ticker) для устойчивости к падениям.
